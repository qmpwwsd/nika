Permission modes and session controls

Design mock for nika 0.3, the visual half of docs/design/spec.md §2.8 and §9. Static: every state is drawn, nothing is wired. Light on the left, dark on the right (stacked on narrow windows). All names, paths and panes are synthetic.

Every mode at a glance

Each mode changes three things at once: the 3 px frame along the top of the window, the tag in the header, and the left edge of the message box. Colour, icon and word always travel together. The dark strip in each card is Claude’s own footer, in Claude’s colour, so the app and the mirror can be compared.

Mode tags next to status pills

Modes are square-cornered tags with an edge; agent status stays a round pill with a glyph. Bypass is the only filled tag. Unconfirmed tags are hollow and dashed and carry the word. Icon-only tags appear only in narrow dashboard rows, where the name stays in the accessible name and tooltip.

Mode switcher

A segmented toolbar: one Tab stop, ← → move, Enter or Space switches. It never hides; when it can’t act it says why, right next to it, using the first reason that applies (numbered 1–5 below). Results of a switch appear in the same place.

Quick actions

Stop is always in the first slot so the row never shifts; it is live only while Claude works. Compact, Clear, Model and Rewind are live only while Claude waits. When something is off, a short line under the row says why. End session is the only red action and is pushed to the far right. Paused mirror and pass-through change nothing here.

Shell toggle

Shell has its own look: ink. On, the toggle fills, says “on”, the prompt sign turns into “!”, and the message box gets a heavy ink edge in place of the mode edge. It turns itself off after each send.

Command palette

Typing / as the first character opens the list above the message box; never while Shell is on. The first option is active on open and after each keystroke; Enter inserts it (an exact name match ranks first). Each row: name and arguments, where it comes from, what it does, and a note when it opens a dialog inside the terminal.

End session

A confirm dialog, focus on Cancel. While nika waits for Claude to exit, Escape and Cancel do nothing. Failures show a fixed message in the alert slot and offer only Close. Copy resume command lives in the dashboard row menu.

Dashboard rows

A mode column right after status, app tier only. Rows without a live pane leave it empty. An unconfirmed (held) mode is a hollow dashed tag, as on reviewer-2 while its prompt covers the footer; the word moves to the tooltip and the accessible name. At ≤ 860 px the tag drops to its icon, like the status column drops to its glyph.
