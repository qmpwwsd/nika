    Panes and limits

    1 to 8. Counts only agents nika spawned that are still running.

    Plugins per project

    Installed plugins to turn on in a project. nika writes them into .claude/settings.local.json when you apply rules.

    Plugins

    Ticked plugins are turned on and other plugins that are on in that file are removed when you apply rules. Leave all unticked to leave the file's plugins as they are.

    Rules template

    Local templates are Markdown files in the templates folder next to config.json. Projects whose rules came from another template show “Rules outdated”.
